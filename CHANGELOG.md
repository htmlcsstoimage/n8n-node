# Changelog

## 0.2.0

- Fix the n8n codex node identifier and remove an unsupported category
- Update the bundled TypeScript client
- Add image deletion
- Add response URL format, deduplication duration, storage destination, and transparent background options
- Add typed custom request headers, additional header origins, subrequest forwarding, and HCTI request identification for URL screenshots
- Support output formats for template creation and signed template URLs

## 0.1.1

- Publish releases through npm Trusted Publishing with GitHub OIDC
- Automatically publish and create a version tag when the package version changes on `main`

## 0.1.0

- Initial HTML/CSS to Image API node
- HTML/CSS, webpage, template, and signed URL operations
- Optional binary PNG, JPG, WebP, and PDF output
- Build-time integration with the official TypeScript client submodule
